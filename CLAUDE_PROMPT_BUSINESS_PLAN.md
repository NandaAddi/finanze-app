**KONTEKS BISNIS "FINANZE" (Gunakan informasi ini sebagai bahan tulisanmu):**

**A. Tentang Finanze & Deskripsi Produk**
Finanze adalah aplikasi *Personal Finance Manager* bergaya minimalis dan premium (terinspirasi dari UI Claude.ai). Aplikasi ini mengonsolidasikan semua aset (rekening bank, e-wallet, uang tunai, kripto) ke dalam satu *Centralized Dashboard*. Finanze berbeda dengan pencatat keuangan manual karena memiliki 2 fitur unggulan:
- **Pemindai Struk Otomatis (OCR):** Pengguna cukup memfoto struk belanja, dan data (nominal, nama toko, tanggal) otomatis tercatat.
- **AI Financial Advisor (Tenaga AI Alibaba Qwen):** Fitur yang memberikan peringatan dini jika pengeluaran membengkak, dan memberikan wawasan personal tentang cara menghemat uang berdasarkan tren transaksinya.

**B. Latar Belakang & Masalah**
Generasi Milenial dan Gen Z di Indonesia semakin sadar akan investasi, namun terjebak dalam gaya hidup konsumtif. Masalah utama mereka:
1. Punya terlalu banyak akun (BCA, Mandiri, GoPay, OVO, ShopeePay) sehingga sulit melacak total Kekayaan Bersih (*Net Worth*).
2. Malas mencatat pengeluaran manual karena memakan waktu.
3. Tidak bisa menganalisis data keuangan mereka sendiri.

**C. Target Pasar & Analisis Industri**
- Usia 18-35 tahun (Mahasiswa, *First-jobber*, Freelancer, dan Keluarga Muda).
- Industri *Fintech* (Wealth-tech) di Indonesia sedang tumbuh pesat. Masyarakat butuh alat untuk literasi dan manajemen keuangan, bukan sekadar dompet digital.

**D. Model Bisnis (Freemium)**
- **Basic Tier (Gratis):** Maksimal 2 dompet, pencatatan manual tak terbatas, analitik dasar.
- **Pro Tier (Berbayar - Rp29.000/bulan atau Rp299.000/tahun):** Dompet tanpa batas, akses unlimited ke *AI Advisor* dan *OCR Receipt Scanner*, kustomisasi UI premium, Ekspor Laporan PDF/Excel.

**E. Rencana Organisasi (3 Orang Co-Founders)**
Tim terdiri dari 3 orang mahasiswa dengan peran: Hacker (CTO - fokus pada pengembangan Next.js, Supabase, AI), Hustler (CEO - fokus pada bisnis, pitching, keuangan), dan Hipster (CMO/CDO - fokus pada UI/UX minimalis, marketing TikTok/IG).

**F. Rencana Operasional & Teknologi**
- Frontend: Next.js 14, React 19, Tailwind CSS (Sangat responsif dan cepat).
- Backend & DB: Supabase (PostgreSQL) + Edge Functions.
- Security: Clerk Auth (Multi-tenant keamanan enterprise).
- AI Engine: Integrasi API LLM (Alibaba Qwen).

**G. Proyeksi Keuangan (Asumsi Kasar untuk kamu kembangkan)**
- Sumber pendapatan utama dari langganan (Subscription).
- Pengeluaran terbesar: Biaya Server (Vercel, Supabase), Biaya API AI & OCR, dan Biaya Marketing.
- Target: Mendapatkan 10.000 pengguna gratis di tahun pertama, dengan konversi 5% ke pengguna Pro. Tolong buatkan angka-angka proyeksi Laba Rugi, Cash Flow, dan perhitungan BEP (Break Even Point) yang realistis untuk startup SaaS (*Software as a Service*).

**H. Rencana Pengembangan & Exit Strategy**
- **Tahun 1-2:** Fokus akuisisi user dan penyempurnaan AI.
- **Tahun 3-4:** Integrasi Open Banking API (Otomatis tarik data mutasi dari bank lokal tanpa perlu input manual).
- **Exit Strategy:** Akuisisi oleh Bank Digital besar (seperti Bank Jago, SeaBank) atau platform ekosistem besar (GoTo/Grab) yang ingin mengintegrasikan fitur Personal Finance Manager yang canggih untuk nasabah loyal mereka.
